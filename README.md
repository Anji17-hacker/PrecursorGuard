# PrecursorGuard

PrecursorGuard is a Windows ransomware and BYOVD (Bring Your Own Vulnerable Driver) early detection platform.

The project analyzes Sysmon logs, detects suspicious behavior before encryption begins, and assigns a risk score using behavioral analytics and machine learning.

## Features

- Sysmon log analysis
- Behavioral detection engine
- Rule-based detection
- Machine learning risk scoring
- MITRE ATT&CK mapping
- Timeline reconstruction
- PDF incident reports
- Interactive dashboard

## Project Structure

```
dashboard/      Web dashboard
detection/      Detection engine
ml/             Machine learning
reports/        Report generation
scripts/        Utility scripts
data/           Input and processed logs
tests/          Unit tests
docs/           Documentation
```
